# Irodori Studio Roadmap（Phase 2–5）

MVP（Phase 0–1）完了後にこの順で実装する。生成エンジンは **OPT のみ**（Lite 禁止）。

## Phase 2 — スクリプト一括追加と分割 ✅

### 目的

中央パネルに「一括入力」モードを追加し、区切り文字チップ UI で分割してライン一覧へ流し込む。

### 実装手順

1. `src/components/SplitChipPicker.tsx` を追加
   - 表示欄: 選択中チップ
   - ドロップダウン: 全候補を pill でトグル（参照画像のチップ UI）
2. プリセットボタン
   - **標準句読点**: `。` `．` `？` `?` `！` `!` `」`
   - **改行のみ**: `\n`
3. 分割モード
   - `strict`: 区切りごとに 1 行
   - `pack`: 一定文字数（設定可能、既定 80）以内なら複数文を結合
4. `GenerateView` に「一括追加」モーダル（textarea + 分割プレビュー + 確定）
5. 単体テスト相当: `src/lib/splitText.ts` に純関数として切り出し

### 受け入れ条件

- プリセット 2 種がワンクリックで切り替わる
- 個別文字の有効/無効がチップで制御できる
- プレビュー結果を確認してからライン追加できる

## Phase 3 — alkana カタカナ提案 ✅

### 目的

英単語を検出し、Irodori venv の `alkana.get_kana` でカタカナ候補を提示。一括/個別承認。

### 実装手順

1. `python/alkana_suggest.py` — stdin/JSON でテキストを受け、`[{word, kana|null, start, end}]` を返す
2. Tauri command `suggest_katakana(text)` → Python 呼び出し
3. `KatakanaReviewDialog` — 一覧、個別承認/却下、一括承認、手動編集
4. 辞書なし（`None`）は手動入力欄を出す
5. 承認後に行テキストを置換してプロジェクト保存

### 受け入れ条件

- 既知語（Hello→ハロー）が提案される
- 未登録語はスキップまたは手動入力できる
- 一括承認が動く

## Phase 4 — 再生・保存の拡張 ✅

### 目的

連続再生・連結保存・ファイル名規則・音量/スピードの出力反映。

### 実装手順

1. 設定項目
   - チャンク間無音 ms（既定 300）— **実装済み**（設定画面／一括再生／連結保存の初期値）
   - セリフ文字数上限（ファイル名用、既定 20）— **実装済み**
2. 連続再生: 選択範囲 or 全行を順に再生し、間に無音（AudioContext で無音バッファ）— **実装済み**
3. 連結保存: Rust/ffmpeg で無音挿入連結 — **実装済み（一括保存モーダル）**
4. セリフ別一括エクスポート — **実装済み（個別保存タイプ）**
5. ファイル名: `{project}_{index:03d}_{speaker}_{utterance}.wav` — **実装済み**
6. 音量・スピードをエクスポート時に ffmpeg `volume` / `atempo` で適用 — **実装済み**

### 受け入れ条件

- 連続再生で無音間隔が聞こえる
- 連結 WAV が再生できる
- ファイル名が規則どおり・禁則文字が消えている

## Phase 5 — UX / 安定化

### 実装手順

1. 学習ジョブのキャンセル（プロセス kill + UI 状態リセット）— **実装済み**（中断＋完了ステップからの再開）
2. 進捗%: パイプライン step 番号を `STEP n/5` で emit — **実装済み**（ステップセグメント＋ステップ内プログレスバー）
3. OPT ワーカー死活監視（定期 ping）と自動再起動 — **実装済み**
4. Sampling プリセットの名前付き保存/読込（settings 隣の JSON）
5. （任意）参照 wav 条件付け UI — embedding 以外が必要な場合のみ

### 受け入れ条件

- 学習中にキャンセルできる — **実装済み**
- ワーカー落ち後も再生成できる — **実装済み**
- プリセットの往復ができる
