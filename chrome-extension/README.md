# Irodori Studio Reader（Chrome 拡張）

Phase 2–4: 本文抽出・連続読み上げ・サイト別プロファイル・キャッシュ。

## セットアップ

リリースの zip を使う場合:

1. [Releases](https://github.com/TK-design336/irodori-studio/releases) から `Irodori.Studio.Reader_*.zip` をダウンロードして解凍する
2. Irodori Studio を起動する
3. **設定 → ローカル HTTP サーバー** でトークンをコピー
4. Chrome の `chrome://extensions` → デベロッパーモード →「パッケージ化されていない拡張機能を読み込む」で解凍したフォルダを選ぶ
5. Side Panel でベース URL とトークンを保存 →「接続テスト」

開発中のフォルダを直接読む場合は、リポジトリの `chrome-extension` を手順 4 で指定してください。

## 使い方

- **このページを読み上げ** … サイト専用 fetcher（なければ Readability / プロファイル）で本文抽出 → 文分割 → 先行合成 → ギャップレス再生
- **選択範囲を読み上げ** … コンテキストメニューから。ページ読み上げと同じ分割・ジョブ再生（`/v1/jobs` は `split: false`）
- ⏮ ⏯ ⏭ ■ / 速度・音量 / 話者変更（未生成チャンクから反映）
- **全体を連結して保存** … ページのキャッシュから wav / mp3 / m4b（未キャッシュ分だけ合成）
- **後で読む** … キューに溜めて順に再生
- 小説サイトは「次話へ自動継続」可能
- 青空文庫はルビ（`<rt>`）を読みとして採用

## 本文抽出

クラス名 1 本に依存せず、JSON-LD / 同一オリジン API / 複数セレクタ / 意味タグの順で拾う。ファミリー内の差分はセレクタだけに閉じる。

| 系統 | サイト | 要点 |
| --- | --- | --- |
| 小説 | なろう / ムーンライト / カクヨム / ハーメルン / アルファポリス | 本文 + 次話リンク |
| 青空文庫 | aozora.gr.jp | ルビは読み優先 |
| ニュース | Yahoo!ニュース / NHK | ペイウォール検知を共有 |
| 長文 | 文春 / 東洋経済 / ダイヤモンド / 現代ビジネス / PRESIDENT | ページ送りを同一オリジン fetch で結合 |
| ブログ・UGC | note / はてなダイアリー・ブログ / 匿名ダイアリー | note は `/api/v3/notes` を優先 |
| Google ドキュメント | docs.google.com/document | Canvas 本文は `/export?format=txt` で取得。コピー禁止は不可 |
| その他 | Wikipedia など | 脚注・関連項目以降は切る |

有料記事は公開範囲だけ読み上げ、警告を出す。

## 注意

- タブ切替やサイドパネルを閉じても、Offscreen で再生と先行合成は続きます
- 停止は ■ ボタン。パネルを閉じるだけではジョブはキャンセルしません
- Studio 未起動時は分かりやすい接続エラーを表示します
- `<all_urls>` はインストール時には要求しません。初回の読み上げ時にサイトアクセス権限を求めます（Wikipedia / 青空文庫を含む全 http(s) ページ）
